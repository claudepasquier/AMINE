# AMINE benchmarks

This directory holds everything needed to reproduce the evaluation and
comparison of AMINE against competing active-module-identification tools.

## Layout

```
benchmarks/
├── competitors/        # third-party tools (BioNet, COSINE, GIGA) — see SOURCES.md
├── artificial/         # parameterised artificial-network grid (preproc × embed × cluster)
├── real/               # real-data runs (e.g. TCGA)
└── methods.xlsx        # the comparison table (regenerated by update_methods_table.py)
```

## Artificial-network grid

The grid is driven by the benchmark processor ported from the historical
experimental code:

```bash
python -m amine.benchmarks.process_artificial_network \
    -g gencat -c amine -e node2vec -p keep_edges \
    -n 1 -m 10 -s 1000 -r 10 \
    --output results.txt
```

The three axes are:

* **preprocessing** (`-p`): `original`, `keep_edges`, `merge`, `none`
* **embedding** (`-e`): `pecanpy`, `node2vec`, `fasttext`, `spectral`, `svd`,
  `randomwalk`, `none`
* **clustering** (`-c`): `amine`, `louvain`, `alouvain`, `dbscan`, `optics`,
  `flame`, `affinity`, `bestvalues`, `in_progress`, `my_flame`

## Competitors

The R/Perl drivers for BioNet, COSINE and GIGA are preserved under
`competitors/`. See [`competitors/SOURCES.md`](competitors/SOURCES.md) for
provenance, upstream references and usage.

## Regenerating `methods.xlsx`

Once the grid and the competitor runs have produced their result files, run:

```bash
python benchmarks/update_methods_table.py
```

to rebuild `methods.xlsx` from the collected metrics.
